# کلاس‌لاین — صفحه و مینی‌اپ

صفحه‌ی لینک‌های مهم کلاس‌لاین؛ هم به‌عنوان وب‌سایت (GitHub Pages) و هم به‌عنوان مینی‌اپ ربات کار می‌کند.

## فایل‌ها
- `index.html` — ظاهر و منطق صفحه (معمولاً لازم نیست دست بزنی)
- `content.js` — **همه‌ی محتوا اینجاست**: بخش‌ها، لینک‌ها، توضیح‌ها
- `assets/logo.png` — لوگوی سفید کلاس‌لاین (روی پس‌زمینه مشکی)

## راه‌اندازی روی GitHub
1. در github.com یک Repository جدید بساز (مثلاً `classline`)، حالت Public.
2. دکمه‌ی **Add file → Upload files** را بزن و همه‌ی فایل‌ها (و پوشه‌ی `assets` با لوگو) را آپلود کن → Commit.
3. به **Settings → Pages** برو. در Source گزینه‌ی **Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و Save کن.
4. بعد از یکی دو دقیقه آدرس صفحه این می‌شود:
   `https://USERNAME.github.io/classline/`

## تبدیل به مینی‌اپ ربات (تلگرام)
1. در تلگرام به `@BotFather` برو.
2. اگر ربات نداری: `/newbot` و مراحلش.
3. `/newapp` را بزن، رباتت را انتخاب کن، عنوان و توضیح بده و در مرحله‌ی URL همان آدرس GitHub Pages را بده.
   (یا: `/mybots` → ربات → **Bot Settings → Menu Button** → آدرس را بگذار تا دکمه‌ی منو، مینی‌اپ را باز کند.)
4. حالا داخل ربات دکمه‌ی منو، صفحه را به‌صورت مینی‌اپ باز می‌کند.

> برای بله و ایتا هم همین آدرس را در بخش مینی‌اپ/وب‌اپ ربات بگذار؛ API آن‌ها شبیه تلگرام است.
> اگر API دقیقاً یکسان نبود، صفحه باز هم به‌عنوان وب‌سایت معمولی درست کار می‌کند.

## ویرایش و کامل‌تر کردن
1. در GitHub روی `content.js` کلیک کن → آیکن مداد (Edit).
2. یک بلوک `{ icon, title, desc, url }` اضافه یا تغییر بده، یا یک `section` جدید بساز.
3. **Commit changes** را بزن. بعد از ~۱ دقیقه هم سایت و هم مینی‌اپ آپدیت می‌شوند — نیازی به تغییر چیزی در ربات نیست.
